# Audio/Podcast Transcript & Chapter Marker Tool

A web-based tool that converts audio/podcast content into text and helps users navigate long recordings using timestamps and chapters. 

## 📖 Project Overview
* **Project Title:** Audio/Podcast Transcript & Chapter Marker Tool.
* **Proposed Application Name:** Audixa.
* **Domain:** Artificial Intelligence + Speech Processing + Web Development.

## ⚠️ Problem Statement
* Manual transcription of long podcasts is highly time-consuming.
* Finding a specific topic in a long recording is difficult, requiring users to listen to recordings repeatedly to find important sections.
* Basic transcription tools lack integrated transcript editing and chapter marking.
* Utilizing multiple separate tools makes the overall workflow complicated.

## 🚀 Proposed Solution & Features
Existing technologies provide speech recognition and audio visualization, but this project bridges the research gap by combining transcription, editing, synchronization, and chapter marking into one seamless web application. 

**Key Features of Audixa:**
* **Speech-to-Text & Time-aligned Transcripts:** Automated conversion of spoken audio into text.
* **Integrated Main Editor:** A unified 3-panel interface combining the audio waveform, transcript, and chapters.
* **Audio Navigation:** Visual waveform seeking to help users easily navigate through the audio.
* **Export Capabilities:** Planned feature to export and save the final transcript.

## ⚙️ System Workflow
1. **Upload File:** Accept Audio/Video inputs.
2. **Audio Processing:** Prepare the input audio.
3. **Speech Recognition:** Process audio via faster-whisper.
4. **Transcript Generation:** Output time-aligned text.
5. **Chapter Generation:** Identify and mark key sections.
6. **Edit & Navigate:** User refinement via Transcript + Waveform editor.
7. **Export / Save:** Output the final verified transcript.

## 💻 Tech Stack & Requirements
**Software Requirements:**
* **Frontend:** HTML5, CSS3, JavaScript.
* **Backend:** Python 3, Flask.
* **Database:** SQLite3.
* **AI & Audio Visualization:** faster-whisper, WaveSurfer.js.

**Hardware Requirements:**
* Laptop/Computer with a minimum of 4 GB RAM (recommended).
* Suitable processor, sufficient storage for media files, and an internet connection.
